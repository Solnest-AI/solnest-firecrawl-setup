# Firecrawl Setup

**A scraper, not just a search engine.** It reads full pages and hands Claude clean text — it can crawl a whole site, pull structured data out of a page, and get past the junk. This is the one that reads Airbnb listings for the Carousel Sniper.

A free setup guide from **Solnest AI**.

## How to use it

1. Download the zip from the Solnest AI Skool community (or **Code → Download ZIP** above) and unzip it.
2. Open **Claude Code**.
3. Drag the whole folder into the chat and say: **"Set this up."**

Claude walks you through it. You don't write any code.

> **You bring your own API keys.** Nothing in this repo contains a key, and your key never leaves your own machine — it's stored in your personal `~/.claude.json`.
